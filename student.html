Aim To create a Jenkins pipeline that performs file handling operations in the Jenkins workspace using Pipeline Script. 2. Requirements - Jenkins installed and running. - Web browser. - Jenkins Pipeline plugin. 3. Procedure 1. Open the web browser. 2. Enter http://localhost:8080. 3. Login to the Jenkins dashboard. 4. Program (Pipeline Script) pipeline { agent any stages { stage('Create File') { steps { writeFile file: 'sample.txt', text: 'Welcome to Jenkins' echo 'File created successfully' } } stage('Read File') { steps { script { def data = readFile('sample.txt') echo "File Content: ${data}" } } } stage('List Files') { steps { bat 'dir' } } } } 4)
